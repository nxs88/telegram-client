# Telegram Client

Тестовое задание — веб-клиент для работы с Telegram через GREEN-API.

## Стек

- React
- TypeScript
- Vite
- Axios

## Возможности

- подключение к GREEN-API инстансу;
- авторизация по `idInstance` и `apiTokenInstance`;
- создание чата по номеру телефона;
- отправка сообщений;
- получение входящих сообщений через long polling;
- отображение списка чатов;
- отображение сообщений выбранного чата;
- автоматическая прокрутка к новым сообщениям;
- обработка ошибок API и ограничения количества запросов.

## Установка

Установить зависимости:

```bash
npm install
```

## Настройка GREEN-API

В проекте используется файл `.env` для указания URL GREEN-API инстанса.

Создайте `.env` на основе `.env.example`:

```env
VITE_GREEN_API_URL=https://your-instance.api.green-api.com
```

В `VITE_GREEN_API_URL` необходимо указать значение `apiUrl` из настроек используемого GREEN-API инстанса.

`idInstance` и `apiTokenInstance` в `.env` не указываются. Они вводятся непосредственно в интерфейсе приложения на странице авторизации.

## Запуск

Запустить приложение в режиме разработки:

```bash
npm run dev
```

После запуска открыть адрес, указанный Vite в консоли.

## Авторизация

На странице авторизации необходимо указать:

- **ID Instance** — `idInstance` из GREEN-API;
- **API Token Instance** — `apiTokenInstance` из GREEN-API.

Для проверки приложения необходимо использовать собственный GREEN-API инстанс.

## Переменные окружения

Файл `.env` содержит конфигурацию локального окружения и не добавляется в Git.

Для проекта предусмотрен файл `.env.example`:

```env
VITE_GREEN_API_URL=https://your-instance.api.green-api.com
```

Перед запуском необходимо создать собственный `.env` и указать в нём `apiUrl` используемого GREEN-API инстанса.
